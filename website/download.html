Desktop app

Debian, Ubuntu .deb x86_64 AppImage

On ARM? Download the arm64 .deb or AppImage. The .deb also installs the tincan CLI.

Terminal

npm install -g @beyland/tincan
tincan setup && tincan service install && tincan pair

Installs the tincan CLI, background daemon, and MCP server without the desktop app. Requires Node.js 22.18 or newer.

Before you install

  • 64-bit Linux (x86_64 or arm64) with glibc 2.35+ — Ubuntu 22.04, Debian 12, Fedora 36, or newer
  • BlueZ 5.64+ (with obexd), OpenSSL 3, and systemd
  • A Bluetooth adapter (built-in or USB)
  • An iPhone nearby

An iPhone shares messages with only one computer or car at a time, so disconnect other Bluetooth messaging apps first. Run tincan doctor or open the app to check your setup and see how to fix anything missing.

On Ubuntu 24.04+, AppArmor may block the AppImage's Chromium sandbox. Use the .deb (which includes an AppArmor profile) instead of passing --no-sandbox. Install guide →

Verify your download

sha256sum --check --ignore-missing SHA256SUMS
gh attestation verify Tincan-*.AppImage --repo beyland-dev/tincan

Every release includes SHA256SUMS and signed GitHub Actions build attestations (works for the .deb as well).

Tincan is early alpha software — expect rough edges and breaking changes before 1.0. All builds and release notes are on GitHub Releases ↗.
